# 予約管理システム

Spring Bootを使用して作成した予約管理システムです。

利用者がWeb画面から予約を登録し、管理者が予約情報の追加・確認・検索・編集・削除を行うことができます。

また、利用者が予約を登録した際には、入力されたメールアドレス宛に予約受付メールを自動送信します。

## 主な機能

### 利用者向け
- 予約の新規登録
- 入力内容のバリデーション
- 予約内容の確認
- 確認画面から入力内容を保持したまま修正
- 予約完了画面の表示
- 予約完了時の確認メール送信

### 管理者向け
- 管理者ログイン・ログアウト
- 管理者からの予約追加
- 予約一覧表示
- 氏名による部分一致検索
- 予約希望日による検索
- 予約受付順での表示
- 予約希望日の近い順・遠い順での並び替え
- 予約詳細の確認
- 予約内容の編集
- 予約の削除

## 予約登録の流れ

利用者は以下の流れで予約を登録します。

```text
予約情報を入力
↓
入力内容を確認
↓
予約を確定
↓
データベースへ保存
↓
予約受付メールを送信
↓
予約完了
```

確認画面で入力内容に間違いがあった場合は、「修正する」から入力内容を保持したまま予約登録画面へ戻ることができます。

## 環境変数

予約受付メールの送信にはGmail SMTPを使用しています。

メールアドレスやアプリパスワードなどの認証情報をソースコードに直接記述しないよう、以下の環境変数を使用しています。

| 環境変数 | 内容 |
| --- | --- |
| `MAIL_USERNAME` | メール送信に使用するGmailアドレス |
| `MAIL_PASSWORD` | Gmailのアプリパスワード |

`application.properties` では以下のように環境変数を参照しています。

```properties
spring.mail.username=${MAIL_USERNAME}
spring.mail.password=${MAIL_PASSWORD}
```

認証情報そのものはGitHubには保存しません。

## 画面URL

アプリケーションを起動した状態で、以下のURLから各画面にアクセスできます。

### 利用者向け

予約登録画面

```text
http://localhost:8080/reservations/new
```

利用者は以下の情報を入力して予約を登録できます。

- 氏名
- 人数
- 予約希望日
- 電話番号
- メールアドレス
- 備考

入力後すぐに予約を登録するのではなく、予約内容の確認画面を表示します。

内容に間違いがある場合は、入力した情報を保持したまま予約登録画面へ戻って修正できます。

予約を確定するとデータベースへ予約情報が保存され、入力したメールアドレス宛に予約受付メールが送信されます。

### 管理者向け

予約管理画面

```text
http://localhost:8080/admin/reservations
```

管理者向け画面へのアクセスにはログインが必要です。

ログイン後は以下の操作を行うことができます。

- 予約の追加
- 予約一覧の確認
- 氏名による検索
- 予約希望日による検索
- 並び替え
- 予約詳細の確認
- 予約内容の編集
- 予約の削除

並び順は以下の3種類から選択できます。

- 予約受付順
- 予約希望日の近い順
- 予約希望日の遠い順

管理者から予約を追加する場合は、電話などで受け付けた予約も登録できることを想定し、電話番号とメールアドレスは任意入力としています。

### デモ用管理者アカウント

学習用サーバーでは、管理画面の機能を試せるように
デモ用の管理者アカウントを使用しています。

- ユーザー名：`admin`
- パスワード：`admin123`

※ 学習・デモ環境専用のアカウントです。
実際に運用する場合は、認証情報を安全に管理する必要があります。

## 制作を通して学んだこと

基本機能の実装後、実際の利用を想定してアプリを操作しながら動作確認を行いました。

画面を見るだけではなく、実際に予約の登録や管理画面の操作を行うことで、使いにくい部分や不足している機能に気づくことができました。

例えば、当初は利用者側から予約する機能を中心に制作していたため、管理者側から新しい予約を追加できないことに動作確認の段階で気づきました。

そこで、管理者側からも予約を追加できる機能を実装しました。

この経験から、Webアプリケーションを開発するときは利用者側だけではなく、管理者側など、それぞれの立場から必要な機能を考えることが重要だと学びました。

また、機能を実装して終わりではなく、実際に操作して改善点を見つけ、修正後に再度動作確認やテストを行うことの重要性も学びました。

## 起動方法

### 1. 環境変数を設定する

予約受付メールを送信するため、以下の環境変数を設定します。

```text
MAIL_USERNAME
MAIL_PASSWORD
```

`MAIL_USERNAME` にはメール送信に使用するGmailアドレス、`MAIL_PASSWORD` にはGmailのアプリパスワードを設定します。

### 2. アプリケーションを起動する

IntelliJ IDEAから `ReservationSystemApplication` を実行します。

または、プロジェクトのルートディレクトリから以下のコマンドで起動できます。

```powershell
.\mvnw spring-boot:run
```

### 3. 予約を登録する

ブラウザから以下の予約登録画面にアクセスします。

```text
http://localhost:8080/reservations/new
```

必要事項を入力し、確認画面で内容を確認してから予約を確定します。

### 4. 予約を管理する

以下の管理者向け画面にアクセスします。

```text
http://localhost:8080/admin/reservations
```

管理者ログイン後、登録された予約の追加・検索・確認・編集・削除などを行うことができます。
